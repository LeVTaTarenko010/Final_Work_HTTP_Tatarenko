# Итоговое задание: Консольный HTTP-сервер на C#

Данный проект представляет собой консольное приложение - HTTP-сервер, реализованный на языке C# с использованием встроенного класса `HttpListener` (без применения сторонних фреймверков).

## 📋 Реализованные маршруты (Routes):

Сервер запускается на порту **6789** и обрабатывает следующие запросы:

1. **`http://localhost:6789/`**
   - Возвращает страницу `wwwroot/index.html`.
   - Содержит текст "Index" и навигационные ссылки на остальные страницы.

2. **`http://localhost:6789/seasons`**
   - Возвращает страницу `wwwroot/htdocs/seasons.html`.
   - **Без использования шаблона:** список времен года (Зима, Весна, Лето, Осень) жестко прописан в HTML-файле.
   - Содержит ссылки для перехода на другие страницы.

3. **`http://localhost:6789/toys`**
   - Возвращает страницу `wwwroot/htdocs/toys.html`.
   - **С использованием шаблона:** список из 5 игрушек формируется на стороне сервера в `Program.cs` и подставляется в HTML-файл путем замены паттерна `{{ toys }}`.
   - Содержит ссылки для перехода на другие страницы.

4. **Обработка ошибок (`default`)**
   - При запросе несуществующего адреса возвращается страница `wwwroot/htdocs/error.html`.
